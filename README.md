# Navathon-III Sistema inteligente de administración del agua

## 1. Descripción del proyecto

Este proyecto consiste en desarrollar un sistema inteligente de administración del agua que permita medir y controlar el nivel del agua, registrar las mediciones obtenidas y visualizar la información mediante una página web.
El sistema integra una maqueta física con sensores y actuadores, una API para intercambiar información entre los componentes, una base de datos para almacenar los registros y una interfaz web para consultar el estado del sistema.
El objetivo es conectar las distintas áreas de desarrollo para construir una solución funcional, en la que los componentes físicos y el software trabajen de manera coordinada.

## 2. Objetivos

- Medir el nivel del agua mediante sensores.
- Procesar y utilizar las mediciones obtenidas.
- Registrar las mediciones y los eventos relevantes en una base de datos.
- Permitir el intercambio de información mediante una API.
- Mostrar el estado del sistema y sus mediciones en una página web.
- Evaluar la implementación de mecanismos de control automático.
- Integrar los componentes físicos y digitales en un único sistema.
- Documentar la instalación, el funcionamiento y las pruebas realizadas.

## 3. Áreas del proyecto

El desarrollo se divide en cuatro áreas principales. Cada encargado debe documentar su parte, explicar cómo se utiliza y mantener actualizada la información correspondiente.

### 3.1. Desarrollo Web
#### Descripción

Esta área se encarga de desarrollar la interfaz web mediante la cual los usuarios podrán consultar la información del sistema de administración del agua.
La página web funcionará como un panel de visualización para mostrar las mediciones recibidas, el estado del sistema y los eventos o alertas registrados.

### 3.2. Desarrollo de APIs
#### Descripción

Esta área se encarga de desarrollar la API que permite la comunicación entre los componentes del sistema.

La API funciona como intermediaria entre los componentes que generan o procesan información, interactua con la base de datos consultando y validando datos, y proporciona informacion a la página web. Su función es definir cómo se envían, reciben, consultan y validan los datos.

El resultado final esperado es desarrollar un sistema inteligente de administración del agua que permita medir el nivel del agua mediante sensores, procesar y almacenar las mediciones en una base de datos y visualizar la información en una página web.
